# Architecture Decision Records

Один файл на решение: `docs/adr/<PascalCaseName>.md`. Пишется в конце задачи (шаг ADR в `/task`) и фиксирует решения так, как они реализованы.

Шаблон:

```markdown
# <Название>

## Status
Accepted. Implemented for issue #<N>.

## Context
Что было и почему понадобилось решение.

## Related ADRs
- [[OtherAdr]] — как связано.

## Decisions

### 1. <Решение>
**Decision.** Что сделано.

**Alternatives.**
- Вариант — почему отклонён.
```
